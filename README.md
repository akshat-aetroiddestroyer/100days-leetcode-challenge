## 💡 My Approach

For every problem, I aim to:

1. Understand the problem and its constraints.
2. Develop a logical approach before coding.
3. Implement the solution in Python.
4. Test edge cases and debug errors.
5. Analyse time and space complexity.
6. Explore a more efficient solution when possible.

The goal isn't just to solve problems—it's to understand **why a solution works and when to use it**.
